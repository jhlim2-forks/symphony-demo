# 할 일 관리 웹앱

팀원이 브라우저에서 할 일을 적어 두는 작은 웹앱입니다. 기능은 요청 하나씩 이슈로 받아, AI 팀원이 문서와 코드를 쓰고 사람이 PR 병합으로 승인하며 키워 갑니다.

- 진행 상황: [프로젝트 보드](https://github.com/orgs/jhlim2-forks/projects/5)
- 무엇을 만들기로 했는지: [요구사항](docs/requirements.md), [설계](docs/design.md)
- 문서와 테스트의 규칙: [docs/README.md](docs/README.md)

## 지금 되는 것

- 할 일 제목을 입력해 추가하기(빈 제목, 200자를 넘는 제목은 거절)
- 추가한 순서대로 목록 보기
- 할 일이 없을 때 안내 문구 보기

## 일하는 방식

1. 요청은 이슈 하나에 하나씩 적고 보드의 `접수`에 올립니다.
2. 기획 담당 AI가 요청을 문서와 비교합니다. 문서에 정해 둔 동작이 아니면 문서 PR을, 이미 정해 둔 동작이면 구현 PR을 엽니다.
3. 자동 검사와 검토 담당 AI의 검토를 거친 PR만 승인자에게 리뷰 요청으로 옵니다. 승인자는 PR을 병합해 승인하고, 고칠 점은 **Request changes**로 남깁니다.
4. 사람이 정할 일이 생기면 봇이 이슈에서 승인자를 @멘션해 묻습니다. 답할 때는 `@symphony-bot-dev`를 함께 적습니다.

원칙은 둘입니다. `main`에 병합된 문서 없이 개발하지 않고, 사람의 승인 없이 문서나 코드를 반영하지 않습니다. `main`에는 `자동 검사`를 통과한 PR만 병합할 수 있습니다.

## 실행

Go 1.22 이상이 필요합니다.

```sh
go run .
```

브라우저에서 http://127.0.0.1:8091 을 엽니다. 다른 주소를 쓰려면 `go run . -listen 127.0.0.1:9000`처럼 지정합니다. 할 일은 서버 메모리에만 보관하므로 서버를 다시 켜면 목록이 비어 있습니다.

```sh
go test ./...
```
